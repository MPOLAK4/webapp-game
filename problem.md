# Problem

Some people have the problem with wanting to play the infamous 'dinosaur' game, featured on Google's Search page when the internet is down, however they still want the internet to be enabled. There's a bit of friction in actually figuring out how to do the workaround, so this app should exist.

## Initial requirements

<!-- Give every requirement an ID so tests can cite it later:-->
R1. A game about the player controlling a dinosaur
R2. Gameflow works like Google's Dinosaur game; escalating difficulty, dodge obstacles by using the space bar
R3. Save file/cookie storage to store the high score.
